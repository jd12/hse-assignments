**Notes**  
**Hard gate: a working end-to-end skeleton is required this week.** However ugly. Input goes in one end, something comes out the other, and you can demo it live.

If you cannot demo a skeleton, we cut scope, not extend the deadline. Come talk to me Monday, not Friday.

**Deliverable**  
Live skeleton demo + `SPRINT3.md` with your current metric number against your baseline + tier confirmation or downgrade.

3. Did you consider a tier downgrade? What decided it either way?
4. What is the one remaining piece that everything else waits on?
5. Three weeks from now the code freezes. What will you not have time to build, and how are you choosing what to drop?
